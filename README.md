# Laborator 2 - Dataset

Am ales un set de date cu cele mai bine cotate 1000 de filme de pe IMDB, luat de pe Kaggle (IMDB Movies Dataset, fisierul imdb_top_1000.csv). Domeniul este cel al filmelor, iar fiecare rand din fisier este un film. Fisierul are 1000 de randuri.

Proprietatile inregistrate in Recombee:

- title (string): titlul filmului
- released_year (int): anul aparitiei
- runtime (int): durata in minute
- genre (set): genurile filmului
- imdb_rating (double): nota de pe IMDB
- meta_score (double): scorul de pe Metacritic
- no_of_votes (int): numarul de voturi
- director (string): regizorul
- overview (string): scurta descriere a filmului
- gross (int): incasarile filmului
